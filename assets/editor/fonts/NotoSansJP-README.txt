NotoSansJP-Regular.ttf
  Noto Sans JP (Regular, wght=400) を、日本語 UI 向けに文字を絞った(サブセット化した)もの。
  出どころ : https://github.com/google/fonts/tree/main/ofl/notosansjp (NotoSansJP[wght].ttf)
  ライセンス: SIL Open Font License 1.1 (LICENSE-NotoSansJP-OFL.txt)
             Copyright 2014-2021 Adobe (http://www.adobe.com/)
  加工内容 : 可変フォントの wght=400 を固定し、ヒンティングを外し、次の文字だけを残した。
             ASCII / Latin-1 / JIS X 0208 全体(第1・第2水準漢字 + 記号・かな・ギリシャ・キリル・罫線) /
             JIS X 0213 面1(第3・第4水準漢字) / CP932 の NEC 特殊文字(丸数字・単位記号など) /
             半角カナ・全角形・一般句読点・矢印・数学記号・図形・CJK 記号。
  用途     : エンジンの既定 UI フォント。プロジェクトに assets/fonts/ のフォントが無いとき、
             BuildGame が game.pak へ同梱し、ゲームの UI テキストに使う。
