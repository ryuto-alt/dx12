# エディタのアイデンティティ（ネオン・エッジ）とテーマ

Uno Engine のエディタの見た目は、フェーズ 1a（2026-09-30）で **案 A「ネオン・エッジ」+ 案 C「インク・アンド・シグナル」の色の節度**に確定し、
既定（`Variant::Default`）になった。起動画面・ランチャーの「暗い面 + 青いネオンのグロー」と同じ世界観をエディタ全体へ広げたもの。

| テーマ | 名前 | 位置づけ |
|---|---|---|
| **Default** | ネオン・エッジ | **既定。** 藍寄りの暗い面。光るのはフォーカス / 選択 / アクティブ / ドラッグ中だけ |
| B | グラス・レイヤー | 別テーマ（将来のテーマ切替の下地）。半透明のガラス・大きな角丸・浮遊感 |
| C | インク・アンド・シグナル | 別テーマ。ほぼ無彩色 + シグナルのライム 1 色 |

旧 Default（第 1〜3 波の UE5 風）と旧案 A は無くなった（`--theme-variant a` は既定と同じ扱い）。比較資料は
`dx12-ui-audit/identity/IDENTITY_OPTIONS.md`。

## 採用した値（`ThemeVariants.h` の `MakeDefault()`）

- **面**: Bg0 #090A10 / Bg1 #11131B / Bg2 #181B26 / Bg3 #232736 / Bg4 #2D3247。入力欄 #0A0B12（枠 #272C3F、hover #414A69）。ポップアップ面 #141721。
- **アクセント**: #2F96FF（hover #62B4FF / pressed #1C7BE6）。アクセント塗りの上の文字は暗い紺 #06101F（4.5:1 以上）。選択面 = アクセント 22%。
- **文字**: #DCDFEC / #C1C6D8 / #A0A6BC / #9299B2（全て各面で AA 4.5:1 以上。`ThemeVariantTests` が固定）。数値は等幅（Cascadia）。
- **状態色**: Good #4FD08A / Warn #F0B04A / Bad #FF7570 — **意味のある通知だけ**に使う（色付きの羅列を避ける）。
- **種別色（アイコン tint）**: 旧案 A より彩度を一段落とした 11 色（最大彩度 < 0.62）。種別は形で見分け、色は控えめ（案 C の規律）。
- **形**: 角丸 窓 0 / 入力 3 / ポップアップ 6 / タブ 4 / 線幅 1px / 分割 3px。
- **光（`Deco`）**: グロー 0.8（旧案 A は 1.0）/ ホバーのにじみ 0.05 / 状態遷移 110ms（ease-out 相当）/
  フォーカス中パネルのエッジライト / 選択行 = 左 2px のネオンバー + 右へにじむ光 / 見出し左の光片（開いている時）/
  ステータスバー上端・ツールバー下端の光の線 / **浮遊物（ポップアップ・メニュー・パレット・トースト）は案 B から「影 0.70 + 内側の白い縁 0.10」を借りる**。

## 構造

- `src/editor/ThemeVariants.h` … 純データ。`Spec { Palette pal; Metrics m; Deco deco; }`。`MakeBase()`（装飾なしの土台。B / C が差分だけ書く）→ `MakeDefault()` / `MakeB()` / `MakeC()`。
- `src/editor/EditorTheme.h` … トークン（`theme::Bg0` 等）は可変。`SetVariant` が書き換え、`ApplyStyle` が ImGuiStyle へ流す。
- `src/editor/UiWidgets.{h,cpp}` の **`ui::deco::`** … 共通の装飾ヘルパ。**後続（ノードグラフ・タイムライン・マテリアルエディタ）はこれだけを使う**（16 進を各パネルに書かない）:

  | ヘルパ | 用途 |
  |---|---|
  | `Ease(id, slot, target)` | hover / active / focus の滑らかな遷移（0..1）。ノードのホバー・選択に |
  | `Glow(dl, mn, mx, rounding, col, strength)` | 矩形の外へ広がるハロー。ノードのカード・選択に |
  | `Halo(dl, center, radius, col, strength)` | 点の発光。ピン・キー・プレイヘッドの頭に |
  | `EdgeLine(dl, a, b, col, alpha)` | 中央が明るく両端へ消える光の線（水平 / 垂直）。プレイヘッド・配線・区切りに |
  | `RowFace` / `SelectionBar` / `CardSelected` | 行・カードの選択表現 |
  | `FloatingCard` | 影 + 面 + 縁の浮遊カード（トースト等） |
  | `PaintChrome` | EndFrame で窓の外側から足す装飾（パネルのフォーカスエッジ・選択タブの光・ポップアップの影とリム・ツールバー / ステータスバーの線） |

  部品として `ui::LabelDropdownButton`（アイコン + ラベル + 値 + ▾）と `ui::Chip`（選択 / 非選択のプリセット）も足した。
- `Gui` ライブラリは `Editor` に依存できないので、`PaintChrome` は `theme::g_paintChromeFn`（`EditorLayer` が設定）経由で呼ぶ。

## 守ること

- 色・寸法は `EditorTheme.h` のトークンと `ui::Px()` だけ。テーマ固有の値は `ThemeVariants.h` に足す。
- 新しい装飾は `deco::` に足す。呼び出し側（各パネル）はテーマを見ない。
- 光るのは「フォーカス・選択・アクティブ・ドラッグ中」だけ。静止した装飾にグローを足さない（長時間の疲れと「光り物」化を避ける）。
- DPI 100〜200% で崩れない（`Px` / `PxF`。ビューポートの輪郭も `theme::Scale()` で太さと探索半径が比例する）。
- 検証: `tests/theme_variant_test.cpp`（既定値の固定・文字コントラスト AA・レイアウト不変・往復）/ `--ui-tests-run-all`。

## 3D ビューポート周りの決まり（フェーズ 1a）

> ★**ゲーム画面の中には何も重ねない**。エディタ専用の表示は「ビューポート枠の別帯」か「バックバッファへ足す後処理」に置き、
> `screenshot_final` / `dx12_perceive`（撮影は ImGui と後処理より前）には写らない。

- **ビューポート専用ツールバー**（`panels/ViewportToolbar.{h,cpp}`）: 3D の上端の別帯（高さ 38px）。EditorLayer が 3D の矩形をその分だけ縮める。
  中身: 移動 / 回転 / 拡縮 / ローカル・ワールド | スナップ（位置・回転・スケールの量つきポップオーバー）| ビューモード |
  表示フラグ | カメラ（速度・視野角）| アスペクト | ブックマーク 1〜9 | 一時表示（スナップ量・カメラ速度）| ビューキューブ。
  Play 中も帯は同じ高さのまま（Editor ⇄ Play で 3D の矩形を揺らさない）。`view.viewportBar` で隠せる（隠すと従来と完全に同じ矩形）。
- **アスペクト**: 既定 16:9（従来の固定と同じ）。16:10 / 21:9 / 4:3 / 1:1 / 9:16 / フィット。Play 中は常に 16:9。
- **ビューモード**: ライティングあり / デプス / 法線 / ラフネス / メタリック / AO（`RenderDebugPass` を編集時の主ビューへ被せる。法線・ラフネス・メタリックは G-Buffer が要る
  ＝TAA / SSR / SSGI のどれか、AO は SSAO が有効なときだけ選べる）/ ワイヤ（エディタ専用の後処理）。アンリットは描画側に切替が無いので未対応。
- **選択アウトライン**（`SelectionOutline.{h,cpp}` + `shaders/editor/SelectionOutline.hlsl`）: 選択 / ホバーの物を R8G8 のマスクへ塗り、外側の縁（芯 + 光）を
  アクセント色でバックバッファへ重ねる。ピッキングは従来どおり CPU の三角形精密。選択が無ければ 1 命令も記録しない。
  既存の AABB 橙ワイヤは既定 OFF（帯 > 表示 > バウンディングボックスで戻せる）。
- **矩形選択**: 空所から左ドラッグ（4px 超）→ 離すと矩形へ完全に収まる物（メッシュ = 投影 AABB / ライト・カメラ = 位置）を選ぶ。Ctrl / Shift で追加。
- **ビューキューブ**: 帯の右端。面をクリックでその面の側からなめらかに（0.35 秒）カメラ移動。手動操作を始めると補間は止まる。
- **ブックマーク**: `Ctrl+1〜9` で保存 / `1〜9` で移動（プロジェクトの `.dx12/viewport_bookmarks.txt` に保存）。
- **ギズモ**: ImGuizmo の強調色をアクセントに揃えた。軸色は X 赤 / Y 緑 / Z 青のまま（彩度を少し落とした）。
- 純ロジックは `ViewportLogic.h`（`tests/viewport_logic_test.cpp` が単体で検証）。

## ワークスペース / レイアウト / 下部ドック（フェーズ 1b）

- **レイアウトの持ち方**: ImGui の ini 文字列ではなく自前の `ws::Layout`（`WorkspaceLogic.h`。分割比 4 本 + 開いているツール窓 + 窓ごとの配置先の上書き + 下部ドックのタブ）で持つ。
  DPI 非依存（比率）・壊れた JSON は検出して既定へ・単体テスト可能。フローティング窓の位置だけは `imgui.ini`（ユーザーデータ領域 `%APPDATA%\DX12Engine\imgui.ini`。旧 = カレントディレクトリ依存）に任せ、1a の DPI マーカー換算はそのまま効く。
- **分割比**: 既定 左 18% / 右 24% / 下 33%（1a までと同じ）。スプリッタを動かした差分だけを取り込んで保存する（ImGui 内部の丸めで毎回少し縮む drift を避ける）。
  ドックは起動時・リセット・右分割 / フローティングへの配置先変更でだけ作り直し、ツール窓の開閉・ワークスペース切替・最大化は既存ノードの `SizeRef` を書き換えるだけ（タブの選択状態を保ち、ビューポートが縮み続けない）。
- **保存先**: `%APPDATA%\DX12Engine\editor_state.json` の `"prefs"`（`EditorPrefs.h`。`DX12E_DATA_DIR` で分離）。`layout.current`（今のレイアウト）/ `workspace.state`（ワークスペースごとの最後の状態）/ `layout.named.<名前>`（名前つきレイアウト）。
  `--background` / UI 自動テスト / 仮想入力中は書き込まない（メモリ上では動く。永続化の副作用でテストが持ち越さない）。
- **ワークスペース**: レベル編集 / マテリアル / ライティング / アニメ・シーケンサー / VFX / UI。ツールバーの「ワークスペース ▾」・`表示 > ワークスペース`・コマンドパレット（`workspace.<id>`）から。
  切替は「今の状態を記憶 → 切替先の最後の状態（初回はプリセット）を適用」。新しく開いたフローティング窓は領域内に重ねて整列する。「中央タブ」化（ビューポートを差し替える広いドック）は未対応。
- **ツール窓の配置先**: 右カラムのタブ（既定）/ 右カラムを分割して並べる / 下部ドックのタブ / フローティング。`表示 > レイアウト > ツール窓の配置先…`。右分割とフローティングはレイアウトを組み直す（ビューポートの大きさは変わらない）。
- **下部ドックのスロット**（`BottomDock.h`）: `bottomdock::Register({id, title, icon, draw})` を 1 回呼ぶだけでタブが増える（S1a シーケンサーのタイムライン用。ダミーの "timeline" を登録済み＝同じ id で本物を登録すれば入れ替わる）。
  タブ帯のダブルクリックで下部ドックを最大化 / 元に戻す（ビューポートには「帯 + 160px」の下限が残る）。
- **上段ツールバー**: 移動 / 回転 / 拡縮 / 空間のボタンはビューポートの帯へ一本化（帯を隠している時だけ上段に代替表示）。
- **16:9 のレターボックス**: 1a のアスペクト設定（既定 16:9・Play 中は常に 16:9・フィット）のまま。ノードが 16:9 でない時の余白は従来どおりクリア色の帯（捨てる面積）。

## UI 自動テストの前面化対策

`build_game` は配布ゲームを起動して 6 秒生きるか見るが、以前は素の起動でゲーム窓が前面に出てユーザー操作を奪っていた。
今は `--background=offscreen,tool` で起動する（GameRuntime も `--background` だけは受け付ける）。UI テスト中は
`guard::TestRunActive()` が立ち、ShellExecute / ダイアログなど OS への副作用は仮想入力モードでなくても止まる。
特定のテストを除外するには `--ui-tests-skip <名前,名前>`（例 `build_game`）。

## テーマを増やす / 切り替える

1. `Spec` 表を足す（`MakeBase()` から差分だけ）。
2. `--theme-variant b|c|default` で起動すると、コマンドパレット（Ctrl+K）に「テーマ: …」が出て実行中に切り替えられる
  （`theme::RequestVariant` → `ImGuiManager::BeginFrame` が NewFrame の前に基準スタイルを作り直す）。
3. 将来のテーマ切替機能はこの表をそのまま「テーマ」として保存・選択できる（`imgui.ini` 側へ記録）。
