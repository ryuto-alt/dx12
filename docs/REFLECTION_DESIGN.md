# 山 2: 室内の反射 設計書（反射プローブ → RT 反射）

2026-10-02 確定。山 1（`GI_FOUNDATION_DESIGN.md`）の続き。RT 反射の詳細は `GRAPHICS_PARITY_DESIGN.md` §2.5.1（RT1）を正とし、本書はそれに反射プローブと受け入れ基準を足して 1 本にする。

## 0. 現状（コードで確認済み）

- 鏡面の環境反射は **空の prefiltered キューブ 1 枚**（`ForwardShade.hlsli:253-266`）。gi.mode=new では「反射方向の空の可視率（DDGI の .a）」で空を弱め、遮られた分を **反射方向の DDGI irradiance（ぼやけた部屋の平均色）** で埋めている（山 1 S3）。最後に SSR が当たった画素だけ SSR で置き換える。
- その結果: **室内の金属・光沢床に部屋の中身が映らない**（映るのは画面内に見えている物だけ＝SSR）。画面外・遮蔽・粗い面はぼやけた平均色。2026-10-01 のギャップ診断の「鏡面が空を映す」は山 1 で軽減したが、「部屋が映らない」は残っている。
- RT 反射は無い（RT1 は設計のみ）。DXR 基盤（RayQuery・バインドレス・TLAS）と DDGI のヒット shading は既にある。

## 1. 方針（確定）

役割分担は Lumen と同じ「**スクリーン → ワールド**」の段重ね。上ほど優先。

| 段 | 担当 | 範囲 | GPU |
|---|---|---|---|
| 1 | SSR | 画面内に見えている物 | 全 GPU（既存） |
| 2 | **RT 反射（R2）** | 画面外・遮蔽。roughness < 0.6 | DXR 対応 GPU のみ |
| 3 | **反射プローブ（R1）** | 上で埋まらなかった画素・粗い面・RT 非対応 GPU | 全 GPU |
| 4 | 空 × 可視率＋DDGI の埋め（山 1 S3） | プローブの範囲外 | 全 GPU（既存） |

- **R1 を先に作る**（全 GPU で効く・粗い面はプローブの方が安定・RT の外れ先にもなる）。R2 はその上に載せる。
- 既存シーンの見た目は変えない（プローブを置かなければ R1 は何もしない。R2 は gi.mode=new の**新規シーンだけ既定 ON**、既存は設定で ON）。`gi.mode` と同じ方針。

## 2. R1 反射プローブ

| 決定 | 内容 |
|---|---|
| コンポーネント | `ReflectionProbe`: 影響範囲の箱（halfExtents）・視差補正の箱（既定は影響範囲と同じ）・境界のぼかし幅・解像度（既定 128、64/128/256）・優先度・強さ。Transform の位置が撮影点 |
| 焼き | エディタ操作（ボタン / MCP）で焼く。撮影点から 6 面を**既存のフォワードで描画**（不透明＋空＋DDGI の拡散。SSR/TAA/ポスト/パーティクル/UI なし。決定論）→ 既存の Prefilter シェーダで GGX のミップ列 → BC6H で保存。プローブ自身は焼き中に写らない |
| 保存 | サイドカー `<シーン名>.probes/<guid>.dds`（焼き結果はバイナリでよい。.nav と同じ扱い）。シーン JSON にはパラメータと焼いた時のハッシュだけ。pak に入る。読み込みは vfs 経由 |
| 実行時 | 全プローブを 1 つの **TextureCubeArray**＋プローブ情報の StructuredBuffer。ルートシグネチャは新しいスロットを取らない（`GRAPHICS_PARITY_DESIGN.md` §2.0 の予約: 既存テーブル slot 11 へのレンジ追加 / PerFrame CB の予約領域）。上限 64 個（超えたら優先度→距離で選ぶ） |
| 合成 | 画素ごとに影響範囲の箱に入るプローブを優先度順に重み付きで合成（境界でぼかす）。**箱による視差補正**（反射ベクトルを箱と交差させて撮影点からの方向に直す）。重みが 1 に満たない分は既存の段 4。合成結果に鏡面遮蔽（山 1 の可視率）は掛けない（プローブ自体が遮蔽込み） |
| 選び方 | v1 は全プローブを PS でループ（箱の判定は安い。≤ 64）。クラスタ化は計測で必要になったら |
| 焼き直しの合図 | シーンの静的な物・ライト・空が変わったらプローブを「古い」印にして通知（自動では焼かない）。MCP から一覧と焼き直し |
| 置き方 | 手置き（Inspector・ギズモで箱を合わせる）＋「選択範囲にぴったり置く」＋ MCP `reflection_probe`（op: create / bake / bake_all / list / auto）。**auto** は DDGI の部屋の推定（静的箱 GiMigration）から部屋ごとに 1 個置く |

## 3. R2 RT 反射（`GRAPHICS_PARITY_DESIGN.md` §2.5.1 RT1 のとおり）

- SSR の後段で、SSR の confidence が低い画素だけ RayQuery を撃つ。ハーフ解像度・1 レイ/画素・roughness < 0.6・GGX VNDF。出力は SSR と同じ t16（rgb=反射放射輝度、a=confidence）＝**フォワードは無改造**。
- **ヒット shading は DDGI のものを `RtHitShade.hlsli` へ切り出して共通化**（albedo・太陽＋影レイ・点光源・DDGI の間接光・emissive。山 1 で材質の metallic/roughness/tint をヒットに入れたので、それも共通化して使う）。ミスは**反射プローブ（R1）→空**。
- 時間デノイズ（RT-AO のデノイザの方式に倣う）。半透明・アルファマスクは v1 対象外（RT2 any-hit で後日）。
- 予算: 1080p で ≤ 2.5 ms（RTX 5060）。

## 4. 受け入れ（山 1 と同じく「前 / 後 / 正解」を数値と画像でユーザーへ）

正解 = エンジン内パストレーサー（`dx12_render_reference`）。評価ハーネスは山 1 の GR-1〜4（`GI_S1_REPORT.md`）を流用し、**反射用の検証部屋**（クロム球・金属パネル・光沢床・粗い金属・ガラス窓、色の強い壁、画面外の看板）を追加する。判定シーン: 検証部屋＋**MikuOblivion のコピー**（元は触らない）。

| # | 基準 |
|---|---|
| B1 | 既存シーン（プローブ無し・RT 反射 OFF）は決定論スクショ**差分 0** |
| B2 | クロム球・金属パネルに映る部屋の色（領域平均）がパストレーサーと ±0.5EV 以内（R1 のみ / R1+R2 の両方） |
| B3 | 画面外の色の強い物（看板・赤い壁）が光沢床・金属に映る（R2 ON で FLIP 改善を数値で） |
| B4 | 粗い金属（roughness 0.4〜0.7）で空の色が漏れない（青みの比率をパストレーサーと比較） |
| B5 | 性能: プローブ合成 ≤ 0.3 ms、RT 反射 ≤ 2.5 ms（1080p 相当で測れなければ測れた解像度と換算を明記）。焼きは 128 解像度 1 個 ≤ 1 秒 |
| B6 | ビルドしたゲーム（pak）でプローブが効く。RT 非対応のときは R1 だけで破綻しない |
| B7 | ctest・MCP の TS テスト・UI テスト全件（1 で窓なし化したもの）が通る |

## 5. 段階

| 段 | 内容 |
