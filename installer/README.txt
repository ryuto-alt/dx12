Uno Engine
===========
DirectX 12 ゲームエンジン + エディタ

■ 起動
  スタートメニュー（またはデスクトップ）の "Uno Engine" から起動してください。

■ 自動更新
  起動時に最新リリースを確認し、新しい版があれば自動で更新します（管理者不要）。

■ AI 連携（MCP）
  エディタの「ツール > MCP / AI Bridge」窓の「ワンクリックで MCP をインストール」を押すだけです。
  Node.js（無ければ自動で入れます）と MCP サーバを用意し、Codex / Claude Code / Claude Desktop / Cursor
  のうち入っているものへ登録します。既存の設定は消さず、変更前のファイルは .bak に退避します。
  終わったら AI ツールを再起動してください。インターネット接続が必要です。
  コマンドラインからは DX12Engine.exe --install-mcp でも同じことができます。
  MCP サーバ本体: https://github.com/ryuto-alt/dx12-mcp

■ アンインストール
  Windows の「アプリ」設定、または「プログラムの追加と削除」から
  "Uno Engine" を削除してください。

GitHub: https://github.com/ryuto-alt/dx12
