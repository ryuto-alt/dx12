# GroveLab の BGM 設定（GroveJukebox が Play の開始時に読む）
#
# 曲そのものは このフォルダーの 1.mid 〜 9.mid。好きな MIDI ファイルに置き換えれば、その番号の曲が変わる。
# この表では、番号ごとに「画面に出す曲名」と「鳴らすトラック」を指定できる（書かなければ MIDI の中の名前・全トラック）。
#
#   書き方:  番号 = 曲名 ; track=トラック名か番号
#   例:      2 = ありふれたせかいせいふく ; track=MIKU
#
# スピーカーは一度に 1 音しか出せないので、全トラックを鳴らすと「いちばん高い音」を選ぶ。
# 歌のメロディを鳴らしたいときは、歌のトラックを track= で指定する。
# トラック名や番号は、Play したときのログ（[bgm] の行）に出る。
# 文字コードは UTF-8 で保存する。
